Folder ini menyimpan screenshot aplikasi yang dirujuk dari `README.md` di root repository.

Silakan letakkan screenshot aplikasi (format PNG) dengan nama file persis sebagai berikut:

- `dashboard.png` — layar Dashboard
- `daftar_resep.png` — layar Daftar Resep
- `detail_resep.png` — layar Detail Resep
- `tambah_resep.png` — layar Tambah Resep / Tambah Tugas

Contoh path akhir file (harus persis agar gambar muncul di README):

```
docs/screenshots/dashboard.png
docs/screenshots/daftar_resep.png
docs/screenshots/detail_resep.png
docs/screenshots/tambah_resep.png
```

Rekomendasi:

- Format: PNG
- Resolusi: screenshot perangkat mobile (pertahankan aspect ratio)
- Jika ingin, Anda dapat mengganti nama file sebelum commit, tetapi pastikan untuk memperbarui referensi di `README.md` juga.

Terima kasih — letakkan file gambar di folder ini lalu commit untuk menampilkan gambar pada README utama.
